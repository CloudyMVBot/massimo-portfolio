# Exhibition atlas base map

Land geometry: Natural Earth, 1:110m physical land, public domain.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

The land geometry is rendered as ASCII texture and a thin coastline, using an equirectangular projection. Markers represent city centers, not exact venue addresses. Exhibition cities and venue names come from the existing exhibited-work.html page.
